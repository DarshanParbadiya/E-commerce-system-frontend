# Microservices Deployment with Agile & Azure DevOps

This project demonstrates how Agile methodology was applied to **containerize, orchestrate, and enhance** a microservices-based e-commerce platform.  
The work was managed in **Azure DevOps**, leveraging **initiatives, epics, features, and tickets** for structured execution.  

---
## DevOps Workflow Integration  

Pull requests and commits were **mapped back to Azure DevOps tickets**, ensuring a **closed feedback loop** between planning and execution.

## Agile in Action  

Agile methodology was used while enhancing the project for business needs. Work items were broken down into **Initiatives → Epics → Features → Tickets** to ensure transparency, accountability, and continuous delivery.
