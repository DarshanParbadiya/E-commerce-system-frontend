## Technology Selection

### Backend Technology
| Technology | Description | Official Website |
|------------|------------|----------------|
| Spring Cloud | Microservices framework | [spring.io](https://spring.io/projects/spring-cloud) |
| Spring Cloud Alibaba | Microservices framework | [GitHub](https://github.com/alibaba/spring-cloud-alibaba) |
| Spring Boot | Container + MVC framework | [spring.io](https://spring.io/projects/spring-boot) |
| Sa-Token | Authentication & authorization framework | [GitHub](https://github.com/dromara/Sa-Token) |
| MyBatis | ORM framework | [MyBatis](http://www.mybatis.org/mybatis-3/zh/index.html) |
| MyBatis Generator | Data layer code generation | [MyBatis Generator](http://www.mybatis.org/generator/index.html) |
| PageHelper | MyBatis physical paging plugin | [PageHelper](http://git.oschina.net/free/Mybatis_PageHelper) |
| Knife4j | Document production tools | [GitHub](https://github.com/xiaoymin/swagger-bootstrap-ui) |
| Elasticsearch | Search engine | [GitHub](https://github.com/elastic/elasticsearch) |
| RabbitMQ | Message queues | [rabbitmq.com](https://www.rabbitmq.com/) |
| Redis | Distributed cache | [redis.io](https://redis.io/) |
| MongoDB | NoSQL database | [mongodb.com](https://www.mongodb.com/) |
| Docker | Application container engine | [docker.com](https://www.docker.com/) |
| Druid | Database connection pool | [GitHub](https://github.com/alibaba/druid) |
| OSS | Object storage | [GitHub](https://github.com/aliyun/aliyun-oss-java-sdk) |
| MinIO | Object storage | [GitHub](https://github.com/minio/minio) |
| LogStash | Log collection | [GitHub](https://github.com/logstash/logstash-logback-encoder) |
| Lombok | Simplified object encapsulation | [GitHub](https://github.com/rzwitserloot/lombok) |
| Seata | Global transaction management | [GitHub](https://github.com/seata/seata) |
| Portainer | Visual Docker container management | [GitHub](https://github.com/portainer/portainer) |
| Jenkins | Automated deployment tools | [GitHub](https://github.com/jenkinsci/jenkins) |
| Kubernetes | Container management platform | [kubernetes.io](https://kubernetes.io/) |
